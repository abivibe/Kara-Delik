# Kara Delik v1.0.5

## English

### Link resolution refresh

- Improved link resolution for YouTube, Instagram, TikTok and Facebook across MP3, highest-quality MP4 and silent MP4.
- Facebook now tries the local downloader first. Instagram skips identical fallback requests, and TikTok reuses the response that identifies photo posts to resolve regular video links.
- Backup resolvers now run in small parallel groups and stop waiting when one returns a usable stream URL. Streams that return an access denial are skipped without repeating the same request.

- Restored HTTPS certificate validation for the download engine and yt-dlp lookups.
- Hardened Windows file actions so downloaded filenames are treated as data.
- The updater now accepts installer links from the Kara Delik GitHub repository and checks the installer against the release SHA-256 before launch.
- MP3 downloads now require a valid audio stream and publish the file only after successful conversion. TikTok photo posts prefer the original music track in MP3 mode.
- Removed the legacy setup script. The documented Windows build remains available through build_windows.ps1.

## Türkçe

### Bağlantı çözümleme güncellemesi

- YouTube, Instagram, TikTok ve Facebook için MP3, en yüksek kalitede MP4 ve sessiz MP4 bağlantı çözümleme akışı güçlendirildi.
- Facebook önce yerel indirme motorunu deniyor. Instagram aynı yedek isteği tekrarlamıyor. TikTok, fotoğraf gönderisini tanımak için alınan yanıtı normal video bağlantısını çözümlemek için de kullanıyor.
- Yedek sunucular küçük gruplar hâlinde eşzamanlı sorgulanıyor ve bir akış adresi döndüğünde diğer istekler iptal ediliyor. Erişimi reddedilen akışlarda aynı istek tekrarlanmadan diğer seçeneğe geçiliyor.

- İndirme motorunda ve yt-dlp sorgularında HTTPS sertifika doğrulaması yeniden etkinleştirildi.
- Windows dosya işlemleri, indirilen dosya adlarını komut olarak yorumlamayacak şekilde güncellendi.
- Güncelleyici, Kara Delik GitHub deposundaki kurulum bağlantılarını kabul ediyor ve dosyayı çalıştırmadan önce sürümün SHA-256 değeriyle karşılaştırıyor.
- MP3 indirmelerinde geçerli ses akışı gerekiyor ve dosya yalnızca başarılı dönüşümden sonra kaydediliyor. TikTok fotoğraf gönderilerinde MP3 seçildiğinde öncelik gönderinin müzik akışına veriliyor.
- Eski hazırlık betiği kaldırıldı. Windows derlemesi için build_windows.ps1 kullanılabilir.
