## Windows build

The existing build script requires Flutter, Visual Studio Windows C++ tooling/MSBuild, .NET Framework 4.8, and Inno Setup 6. Run `build_windows.ps1` from the repository root. The script builds the app, notifier and updater, runs the updater startup/progress checks, copies native dependencies, and produces `output/KaraDelik_Setup.exe`.

Native tools are excluded from Git by the existing `.gitignore`. Before building, provide:

| File | Version | Location |
|---|---|---|
| yt-dlp.exe | 2026.10.26 | repository root |
| ffmpeg.exe, ffprobe.exe | 9.0.1 Gyan essentials build | windows/bin/ |
| node.exe | 24.19.0 | windows/bin/ |
| Visual C++ redistributable/runtime files | existing Windows build prerequisites | windows/redist/ |

Distribution/source links and licenses are listed in [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md). Media-tool binaries are bundled in the installer; the source archive includes the application, installer, updater and tests.

Run normal checks:

```powershell
flutter test
flutter analyze
powershell -STA -File test/verify_updater_window.ps1
powershell -STA -File test/verify_updater_progress.ps1
powershell -File test/verify_updater_resources.ps1
```

Live network checks are opt-in and perform full downloads:

```powershell
$env:KARADELIK_LIVE_TEST = '1'
$env:KARADELIK_REPEATS = '2'
flutter test test/live_download_test.dart --reporter expanded
```
